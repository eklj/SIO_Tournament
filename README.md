# Plateforme E-sport SIO

## Présentation

Plateforme E-sport SIO est une application web destinée aux étudiants en BTS SIO qui souhaitent jouer ensemble et participer à des compétitions. Elle centralise les profils, les équipes, les tournois, les matchs, les résultats et les classements.

## Objectif

Les étudiants utilisent souvent plusieurs réseaux sociaux et messageries pour rechercher des joueurs et organiser des matchs. L'application vise à réunir ces activités sur une plateforme commune, simple et adaptée aux étudiants en SIO.

## Fonctionnalités principales

- créer un compte et gérer son profil ;
- consulter les jeux disponibles ;
- créer ou rejoindre une équipe ;
- gérer les membres d'une équipe ;
- consulter les tournois et inscrire une équipe ;
- consulter les matchs et enregistrer les résultats ;
- consulter les classements ;
- administrer les utilisateurs, jeux et tournois.

## Technologies envisagées

- **Frontend :** HTML5, CSS3 et JavaScript ;
- **Backend :** PHP 8 avec une API REST ;
- **Base de données :** MariaDB/MySQL ;
- **Communication :** HTTP et JSON ;
- **Serveur :** Apache ;
- **Gestion du code :** Git et GitHub.
