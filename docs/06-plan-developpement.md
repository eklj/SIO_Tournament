# Mission 12 - Plan de développement

## Étape 1 - Préparer le projet

- [ ] Créer l'arborescence du frontend et du backend.
- [ ] Initialiser Git et créer le premier commit.
- [ ] Configurer Apache, PHP et MariaDB.
- [ ] Créer un fichier `.env` local non suivi par Git.

## Étape 2 - Créer les données

- [ ] Créer la base de données.
- [ ] Créer les tables et les contraintes.
- [ ] Ajouter quelques jeux et utilisateurs de test.
- [ ] Tester les relations entre les tables.

## Étape 3 - Développer l'API principale

- [ ] Configurer la connexion PDO.
- [ ] Créer les routes de consultation des jeux.
- [ ] Créer les routes de gestion des utilisateurs.
- [ ] Créer les routes de gestion des équipes et des membres.
- [ ] Créer les routes de gestion des tournois et des inscriptions.
- [ ] Créer les routes de gestion des matchs et des résultats.
- [ ] Créer la route de consultation du classement.
- [ ] Tester les routes avec Postman ou Bruno.

## Étape 4 - Développer le frontend

- [ ] Créer la navigation et la page d'accueil.
- [ ] Créer les formulaires d'inscription et de connexion.
- [ ] Afficher les jeux.
- [ ] Afficher et gérer les équipes.
- [ ] Afficher les tournois et permettre l'inscription.
- [ ] Afficher les matchs, les résultats et les classements.
- [ ] Connecter le frontend à l'API avec `fetch()`.

## Étape 5 - Sécuriser et tester le MVP

- [ ] Hacher les mots de passe.
- [ ] Valider les données reçues par l'API.
- [ ] Utiliser des requêtes SQL préparées.
- [ ] Vérifier les droits du joueur, du capitaine et de l'administrateur.
- [ ] Tester tous les parcours du MVP.
- [ ] Corriger les erreurs et améliorer les messages affichés.

## Étape 6 - Finaliser

- [ ] Améliorer l'affichage responsive.
- [ ] Mettre à jour le README et la documentation.
- [ ] Préparer une démonstration complète.
- [ ] Développer un bonus uniquement si le MVP fonctionne entièrement.
